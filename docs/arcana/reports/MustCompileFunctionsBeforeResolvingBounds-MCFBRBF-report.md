# Accuracy report: Must Compile Functions Before Resolving Bounds (of Functions) (MCFBRBF)

Audited against the working tree on 2026-09-06. Source: reconstructed from citing code — the only trace is a block comment at src/typing/test/compiler_tests.rs:6416-6426, ported verbatim from a 2023 Scala-era test comment (introduced no later than commit 93ed8e9c "Initial commit!" in this repo's history, well before the Scala purge at 01652f58).

## Verdict
MCFBRBF describes a real ordering problem the Scala-era compiler once had (struct bounds like `where func drop(T)void` needing an overload index that didn't exist until functions were compiled), but the "solution" it names — delaying bound resolution until functions are compiled — is not what the current code does. The current struct/interface bound substitution (src/typing/citizen/struct_compiler.rs, `substitute_citizen_own_bounds`) resolves each `func_bound`'s param/return types by evaluating templexes directly against the substituted templata, with no dependency on an overload index and no deferral to "after functions are compiled" — matching the comment's own description of the *normal* (non-problematic) path, not its proposed fix. The regression test the comment sits in (`structs_can_resolve_other_structs_instantiation_bound_arguments`) passes today, so the underlying problem is solved, just not by the mechanism MCFBRBF names; the neighboring `drop_bound_on_a_generic_struct_ignores_the_borrow_blanket` test (compiler_tests.rs:6465) and its own comment describe the real current mechanism (bounds discharged against placeholders at struct-definition time, no instantiation/overload-index step needed). MCFBRBF never had a citing definition elsewhere and today has exactly one site, itself. Delete the citing comment (or replace "see MCFBRBF" with a plain sentence, or point at the real live arcana MFBFDP which covers the adjacent still-current concern about merging function bounds from the overload resolver) — do not migrate it into docs/arcana, since the fix it names does not describe present-day behavior.
