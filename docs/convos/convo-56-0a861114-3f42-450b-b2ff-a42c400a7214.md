In this repro, `dis$0` is the cardboard cutout for `T` — the stand-in value that the dispatcher's generic parameter gets bound to so the switchboard can be compiled once, for all possible `T`s.

Concretely, when `compile_i_tables` compiles

```vale
func drop<T>(virtual this MyOption<T>) void { this match { ... } }
```

it can't leave `T` as a hole — the solver needs every rune to conclude to *some* value. So it mints a **placeholder**: an `ITemplataT::Placeholder` / `KindPlaceholder` whose identity is literally "generic parameter #0 of this dispatcher" (`dis` = dispatcher, `0` = the param's index). Then:

- `T` concludes to `dis$0`
- the `Call` rule fires: `this`'s type becomes `MyOption<dis$0>`
- the body typechecks against that — and since `dis$0` is opaque, whatever the body does is guaranteed valid for *every* concrete `T`

Two things it deliberately is **not**:

- **It's not `int`.** Even though `main` only ever uses `MyOption<int>`, the dispatcher is compiled once against the placeholder, not per instantiation. The instantiator substitutes `int` for `dis$0` later — that's the `substitute_templatas_in_kind` machinery, and the definition-vs-callsite zip-by-rune the handoff keeps warning about.
- **It's not `case$N` or `ri$N`.** Those are the other two placeholder families in Generics.md: `ri$N` is what the *impl* got when it was compiled, and `case$N` is minted per match-arm for a Milano-style independent rune (`ZZ`) that no interface argument determines. ## The legend, distilled

| Token | Meaning |
|---|---|
| `$T` / `$0` | **placeholder** — named after generic param `T`, or the 0-th positional one. `HashMap$T`, `dis$0`, `case$3` |
| `.` | **path separator** between nested denizens. `MySome.bound:drop:66`, `genFunc<int>.lam:2:6` |
| `:loc` | **file-location disambiguator** — `drop:66` (offset), `lam:2:6` (line:col) |
| `<X>` | generic args (use-site) or params (declaration). Bare `Foo` = the *template*; `Foo<>` = *instantiated with zero args* — the `<>` is the visible signal separating the two forms |
| `{X}` | per-call-site tag on a lambda template distinguishing separate compilations of one lambda body — *not* generic args. `__call{bool}` |
| `bound:name` | a bound declared on a denizen. `BorkForwarder.bound:__call` |
| `^X` / `&X` / `*X` | owned / borrowed / shared **coord** prefix — bare `X` is a *kind*, prefixed `X` is a coord, and the distinction is load-bearing |
